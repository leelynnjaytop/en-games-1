🗄 数据备份

所有数据（题库、名单、成绩）都在服务器上的一个 SQLite 文件里。

备份方法：把服务器上的 data/app.db 复制一份就是完整备份。
恢复：停掉服务 → 把备份文件放回 data/app.db → 重启。
重置题库：在服务器项目目录执行 npm run reseed， 会清空题库并恢复内置 60 道题；成绩和班级名单不受影响。执行前建议先导出一份 CSV。
